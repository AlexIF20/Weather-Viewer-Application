# Weather Viewer Application

## Overview

The **Weather Viewer Application** is a web application that provides users with real-time weather information for a selected city. 
It uses APIs to fetch and display weather data such as temperature, humidity, and wind speed as well as photos of that city.

## Features

- **Search by City**: Enter the name of any city to retrieve the current weather data.
- **Real-time Data**: Displays up-to-date weather information.
- **Weather Details**: Shows detailed information including temperature, humidity, wind speed, and weather description.
- **Simple UI**: A clean and intuitive interface built with HTML and CSS.
- **Favorite system**: Save your favorite cities for quick access.
